# Underground storage — chest labels

32 double chests + 12 single chests. Built against the live container index
(`schematics/storage.json`, 179 containers, **212 distinct item types**, ~46k items).
Every one of those 212 types has a home below — nothing falls through to the inbox today.

Sign lines are ≤15 characters, so each label pastes straight onto a sign.
`cap%` is current holdings against that chest's capacity (double 3,456 / single 1,728).

Everything else sits under 90%.

## Three things the split is deliberately doing

- **White wool gets its own chest (13).** It is 6,112 of the 10,300 wool you hold — grouping it with
  the other pale wools guarantees an overflow you have to unpick later.
- **Dirt and sand are labelled CURRENCY (31), not building stock.** On skyblock.net dirt and every
  form of it is money. This is the same rule `blocks.spendable()` enforces in the generator — the
  chest label should say it too, so nobody spends the bank by hand.
- **Wood is split by species, shapes are pooled (08–12).** Species matters when you are picking a
  coat or a palette; a spruce slab and an oak slab are interchangeable when you are building, and
  five separate shape chests would each sit at 3%.

## Keeping it honest

`storage.json` is written by chunkscan as you open containers, so re-run this against it after the
chests are filled and the `cap%` column tells you what to re-split:

```bash
python -m mcbuild storage
```
