# Theme Park Completion Masterplan

> The right-hand Hollow program in this document is superseded by
> [PARK_REPROGRAM_PLAN.md](PARK_REPROGRAM_PLAN.md). Use Prismworks and its
> Isthmus plan for all new work; the older section remains only as history.

## Scope

Complete three coherent lands around the retained anchors: **Big Wheel/Sky
Lift** and **Carousel** in Midway, **Mine Coaster** in Frontier, and **Mirror
Maze** in Hollow. Exact coordinates and elevations come from the approved
WorldSpec and real island capture; this plan intentionally does not invent
coordinates. The Isthmus remains untouched.

The target is a complete player visit, not uniform visual density.

| Public-footprint use | Midway | Frontier | Hollow |
|---|---:|---:|---:|
| Experiences | 34% | 40% | 37% |
| Food, retail, rest, utility | 14% | 12% | 14% |
| Paths, courts, lawns, views | 28% | 25% | 28% |
| Functional scenery/set pieces | 15% | 15% | 13% |
| Backstage, terrain, and intentional reserve | 9% | 8% | 8% |

Functional scenery must orient, frame a view, support a ride, conceal
operations, provide a boundary, or carry a story. It is never permission for
filler façades.

## Park-wide rules

```text
arrival → landmark sightline → clear choice → queue/experience
→ distinct exit → reward, food, rest, or view → signed return loop
```

- Main public routes are 5 clear blocks; returns 3; queues 2–3 and never
  through-routes; concealed service routes are at least 2 blocks.
- Reserve every anchor's approach, queue, exit, service, skyline and below-grade
  volume before neighboring detail generation.
- Most public activity stays in `B-8..B+28`; `B+28..B+80` is limited to
  ride mass, overlooks, and supports. Below-grade content requires a specific
  service or story purpose.
- Big Wheel, Mine Ridge, and Hollow clock/manor mass are the only skyline
  dominants. New height is accent, not competition.
- Every component needs purpose, footprint, vertical band, ownership, typed
  public/service anchors, budgets, scenarios, and review views.

## Midway: sky-fairground

```text
arrival / Isthmus → services + admission → Welcome Court
  ├─ Carousel Court → Games Row → Prize & Treats → hub return
  ├─ Sky Lift Promenade → Big Wheel → gallery → food terrace → hub return
  ├─ Frontier threshold
  └─ Hollow threshold
```

Post-turnstile, the Wheel is the upward/forward pull, Carousel moves to one
side, and both land arches sit on the cross-axis. The centre is an open meet
point, not a booth field.

| ID | Piece | Class | Required player/function value |
|---|---|---|---|
| M01 | Arrival Court | orientation/recovery | Queue-free spawn, map/rules, lockers, guest help, `arrival_spawn → ticketing`. |
| M02 | Admission House | usable support | Box office, covered queue, turnstiles, separate re-entry/staff route, rear service lane. |
| M03 | Welcome Court + Clock Fountain | orientation/set piece | Low meet point, seating, map, event lights, four named branches; never an obstruction. |
| M04 | Carousel Court | primary experience | Retained Carousel with marquee, queue, board, operator rear, exit to games, seating/planting ring. |
| M05 | Games Row | secondary experiences | Three or four distinct bays, each with standing pad, input, feedback, collection/reset, protected rear. |
| M06 | Prize & Treats | reward/recovery | Prize redemption plus snack counter after games, with a side exit to the return loop. |
| M07 | Sky Lift Promenade | approach/view | 5-wide main axis, status board, photo point, queue split visible before entry. |
| M08 | Big Wheel / Sky Lift | primary experience | Retained anchor: station/queue → lift/gallery → dry landing → distinct exit; use an accurate ride name. |
| M09 | Sky Lift Exit Vista | route payoff | A brief protected exit view/photo marker integrated into the return route; no separate passive venue. |
| M10 | Snack Window | recovery | One small counter or vending-style interaction, 4–6 nearby seats, rear service access; no food hall. |
| M12 | Land Thresholds | orientation | 5-wide paved handoff, palette change, destination map/sign and return identity. |

Carousel and Sky Lift are the only long experiences. Games are repeatable short
play; a single snack window is recovery. Do not add a third full-size ride,
food hall, or fireworks terrace.

## Frontier: boomtown and working mine

```text
Midway threshold → Trailhead Landing → Boomtown Main Street → Mining Square
  ├─ Mine Coaster queue/station → ridge/tunnel story → Assay Return
  ├─ Prospecting Porch → short games/rewards → town return
  └─ Saloon / Camp Kitchen → porch seating → return spine
```

The Coaster must read from arrival through its headframe, station, ridge and
trestles. Town is inhabited and useful, not a wall of false fronts.

| ID | Piece | Class | Required player/function value |
|---|---|---|---|
| F01 | Frontier Gate + Trailhead | orientation | Map, wait board, trail sign, covered porch, immediate mine/coaster sightline. |
| F02 | Boomtown Main Street | circulation/recovery | 5-wide social street, 3–4 real porch/interior bays, benches/lamps, rear return/service strip. |
| F03 | Saloon Counter | recovery/social | One compact counter, 6–10 seats, a small ambient interaction, service rear, and distinct street exit; no hall-scale dining. |
| F04 | Assay & Prize Office | reward/support | Coaster/prospecting reward collection, display, counter, secured service back. |
| F05 | Mining Square | orientation/set piece | Open choice point, low ore-cart/claim-board, ride status, queue split, viewing edge. |
| F06 | Mine Head + Coaster Station | primary experience | Retained coaster with real queue, boarding, dispatch, unload, emergency and maintenance access. |
| F07 | Mine Ridge + Trestle Loop | scenic/support | Visible lift, tunnels, stone/timber layers, viewpoint; every trestle supports ride geometry. |
| F08 | Coaster Exit / Assay Return | recovery/reward | Unload → photo/reward/assay → 3-wide return, never through a queue. |
| F09 | Prospecting Porch | secondary experiences | Two or three short games: sluice, target/range, nugget chute; rules, input/outcome/reset, prize direction. |
| F10 | Surveyor's Pull-out | route payoff | One small protected pause built into the coaster return/view route, not a separate destination. |
| F11 | Works Yard / Service Gallery | operations/story | Hidden controls, reset, storage, rail access; one deliberate guest glimpse at most. |
| F12 | Canyon Edge Landscape | scenic/boundary | Pines, rubble, retaining walls, dry creek/contained water to shape views and hide edges. |

The Coaster is the headline; Prospecting gives short replayability; Saloon gives
dwell time; ridge/outlook gives visual reward. Do not add another major rail
ride or rows of empty storefronts.

## Hollow: manor district and crypt discovery

```text
Midway threshold → Hollow Gate → Arrival Court → Clock Street
  ├─ Manor Court / story room → graveyard return loop
  ├─ Crypt Market → Mirror Maze → Reliquary / Mourning Parlour → return
  └─ Clockwork Overlook → optional undercrypt reveal → return
```

Hollow is mysterious, never confusing. Gate framing and a reliably lit 5-wide
Clock Street establish confidence. The Maze is a compact market discovery, not
a reason to make the entire land maze-like.

| ID | Piece | Class | Required player/function value |
|---|---|---|---|
| H01 | Hollow Gate | orientation/set piece | Landmark frame, map/fingerpost, clear gate-to-street route. |
| H02 | Arrival Court | orientation/recovery | Queue-free decision court, services, lockers/rest, wait board, map, landmark sightline. |
| H03 | Clock Street | circulation | 5-wide spine + gate return loop, warm lights, paced façade bays, hidden rear service strip. |
| H04 | Manor Court + Graveyard Loop | playable story | A formal court and 3-wide return loop containing a short, resettable clue/secret-door story beat; if the interaction is cut, reduce this to route/scenery rather than pretending it is an attraction. |
| H05 | Crypt Market Gate | orientation | Maze rules/wait point and visible reward/recovery; prevents queue spill to Clock Street. |
| H06 | Mirror Maze | primary/secondary experience | Retained maze: clear entry, optional score, solvable route, real dead ends, obvious exit, emergency/service bypass. |
| H07 | Reliquary + Curio Counter | reward/retail | Maze-exit prize/display and side market access, separate counter queue, service stock door. |
| H08 | Mourning Parlour | recovery/social | Warm market-edge sitting room with 6–10 seats, a readable social/tabletop or clue-board interaction, and direct return; no food service. |
| H09 | Ossuary Puzzle Crypt | earned discovery | Optional one-room branch: three inputs, visible states, reward, reset and staff access. |
| H10 | Clockwork Threshold | playable transition | A brief, resettable timing/route-choice or observation mechanism at a real decision point; no standalone overlook. |
| H11 | Undercrypt Challenge | optional experience | Only after surface passes: short descent → puzzle/encounter with a clear outcome → a different return. No pure reveal chamber. |
| H12 | Garden, Alleys, Ironwork | scenic/boundary | Lawn, decision-point statues, reconnecting alleys, planted walls; never inaccessible doors. |

Maze is the active core. Manor/clock/graveyard are a playable story sequence;
Ossuary is an earned puzzle; the Parlour is a limited social recovery room.
Do not add a second giant haunted ride until this loop, lighting, and service
work are proven.

## Detail and scenery control

Public faces use recess/base, wall/body, and projection/trim bands. Detail
clusters belong at court edges, protected borders, view termini, or building
bases. Keep intersections, entrances, exits, signs, counters, and instructions
visibly quiet.

| Land | Palette character | Hard constraint |
|---|---|---|
| Midway | painted timber/light stone, dark trim, marquees, small metal/glass, planters/banners | no tall icon beyond Wheel |
| Frontier | weathered timber/dusty stone, soot recess, ore/rail/brass, pines/rubble | no loose rails, unsupported trestles, empty false fronts |
| Hollow | deepslate/tuff/dark timber, iron recesses, sparse copper/warm lamps, moss/vines | mood never replaces lighting or wayfinding |

## Delivery sequence and completion gate

```text
0 capture + strict WorldSpec + protected volumes/view corridors
1 main spines, return loops, service strips, threshold anchors
2 Carousel, Big Wheel, Mine Coaster, Mirror Maze
3 queues, exits, mechanics, safety, and scenario proof
4 food, prizes, seating, maps, services
5 short interactions and story rooms
6 functional set pieces, façades, ridge/garden boundaries
7 landscaping, signage, night pass, visual packet
8 optional underground reveals only after 1–7 pass
```

The infrastructure lane owns shared paths, queues, plot edges, and service
trunks. Module lanes consume typed anchors; they may not redraw neighboring
routes. Assemble only after overlap, support, mechanics, route, budget, and
visual evidence pass.

| Completion gate | Must prove |
|---|---|
| Flow | Arrival reaches every entry; every exit reaches return; queues never share a main route. |
| Function | Rails/maze/games/counters/shows have input, output, reset, and service access. |
| Clarity | Landmark visible at arrival; real signs at choices; one primary choice per decision. |
| Recovery | Seating/food/rest are a short signed walk from major exits. |
| Operations | Concealed service reaches controls; no guest dead ends or exposed machinery. |
| Night and visual | Safe lighting plus day/night approach, queue, exit, return, interior and skyline packet. |
| Skyblock | Profile legality, cost, tile/entity, chunk and vertical-reservation budgets pass. |
